# Безопасность

## Область

Текущая линия разработки — 2.x. Гарантированный срок поддержки и SLA пока не установлены. Для анализа проблемы указывайте точный тег или коммит.

## Сообщение о проблеме

Репозиторий публичный. Об уязвимостях сообщайте владельцу `@Slipcast-dev` закрыто: через [приватное сообщение об уязвимости](https://github.com/Slipcast-dev/VibeWave/security/advisories/new), если оно доступно, или другим согласованным закрытым каналом. Не описывайте уязвимость в открытых issues до исправления.

Не прикладывайте действующие токены, сертификаты, пароли, личную `library.json`, исходную музыку и полные пользовательские пути. Issues видны всем: не публикуйте в них личные данные.

Полезные сведения: версия, macOS, архитектура, воспроизведение на тестовом файле, ожидаемое и фактическое поведение, возможное влияние.

## Ограничения текущего артефакта

Релиз 3.0.0 — универсальное приложение (Apple Silicon и Intel) с локальной ad hoc подписью. Developer ID и нотариализация Apple не выполнены. Не отключайте Gatekeeper или SIP для запуска.

Единственный сетевой доступ — автообновление по HTTPS с GitHub: `update.json` при запуске и архив после согласия пользователя. Данные о пользователе и музыке не отправляются. Описание обновления `update.json` и архив подписаны Ed25519; приложение проверяет обе подписи открытым ключом из `Info.plist`, SHA-256, идентификатор, версию и подпись кода, а установщик повторно сверяет приложение непосредственно перед заменой. Приложение собирается с Hardened Runtime (подпись по-прежнему ad hoc). Закрытый ключ хранится только у разработчика вне репозитория (рекомендуется Связка ключей); его утечка — уязвимость, о которой нужно сообщить немедленно. Библиотека содержит локальные пути; перед обменом журналами и снимками обезличивайте их. Изменение данных и миграции проверяются на временных библиотеках.
