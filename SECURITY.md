# Безопасность

## Область

Текущая линия разработки — 0.5.x. Гарантированный срок поддержки и SLA пока не установлены. Для анализа проблемы указывайте точный тег или коммит.

## Сообщение о проблеме

Репозиторий приватный. Сообщите владельцу `@Slipcast-dev` о проблеме через доступный согласованный закрытый канал. При необходимости создайте issue с минимальным обезличенным описанием для участников проекта; чувствительные подробности передавайте отдельно по согласованию.

Не прикладывайте действующие токены, сертификаты, пароли, личную `library.json`, исходную музыку и полные пользовательские пути. Не переносите содержимое приватного проекта в публичные issues.

Полезные сведения: версия, macOS, архитектура, воспроизведение на тестовом файле, ожидаемое и фактическое поведение, возможное влияние.

## Ограничения текущего артефакта

Релиз 0.5.0 содержит Intel x86_64-приложение с локальной ad hoc подписью. Developer ID и нотариализация Apple не выполнены. Не отключайте Gatekeeper или SIP для запуска. Для доверенного публичного распространения требуется отдельная проверенная конфигурация подписи.

Приложение не использует сетевые функции и ключи API. Библиотека содержит локальные пути; перед обменом журналами и снимками обезличивайте их. Изменение данных и миграции проверяются на временных библиотеках.
