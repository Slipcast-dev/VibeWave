# Иконка VibeWave

Исходник: `AppIcon.png`. Во время сборки из него создаются размеры macOS iconset и файл `VibeWaveIcon.icns`, который включается в приложение и его подпись.

Иконка создана встроенным генератором изображений. Финальный запрос:

> Create a single premium macOS app icon for VibeWave, a minimal local music player. Square 1024x1024 composition. Black rounded square tile, subtly inset, with transparent corners outside tile. A single bold flowing W-shaped audio wave ribbon in luminous violet and lavender, soft restrained purple glow, clean high-contrast silhouette, smooth rounded shapes, minimal and recognizable at small Dock sizes. No text, no letters, no device, no mockup, no surrounding scene, no watermark. Only the app icon.

За пределами скруглённой плитки сохранена прозрачность. Размеры для Finder и Dock создаются системными инструментами sips и iconutil.
